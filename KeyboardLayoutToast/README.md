# Keyboard Layout Toast

Компактная утилита для Windows 11, показывающая название текущей раскладки после её смены. Работает из системного трея, не требует базы данных и не использует сторонние NuGet-библиотеки.

## Требования для сборки

- Windows 11 x64.
- .NET 10 SDK. Во время первой сборки SDK получает стандартные reference packs для Windows из источников Microsoft.

Для запуска готовой portable-сборки .NET устанавливать не нужно: runtime включён.

## Сборка и запуск из исходников

Откройте PowerShell в корне проекта и выполните:

```powershell
dotnet restore .\KeyboardLayoutToast.csproj
dotnet build .\KeyboardLayoutToast.csproj -c Release
dotnet run --project .\KeyboardLayoutToast.csproj -c Release
```

Чтобы создать self-contained сборку Windows x64:

```powershell
dotnet publish .\KeyboardLayoutToast.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\release\win-x64
```

После публикации запускайте `release\win-x64\KeyboardLayoutToast.exe`.

## Использование

Приложение отслеживает смену раскладки в фоне и показывает код с названием языка. Пресет Linux · KDE выводит небольшую полупрозрачную плашку размером 215×41 с иконкой клавиатуры слева и названием языка справа. В трее доступны настройки позиции, смещения от центра, размера и прозрачности. Для тестового показа используйте `Ctrl+Alt+F10`; выход доступен в меню трея.

## Настройки

При первом запуске рядом с программой создаётся `settings.json`. Стартовые значения приведены в `settings.example.json`. Все настройки доступны через контекстное меню значка в трее и применяются сразу.

В меню положения можно выбрать центр, смещение вниз от центра `0×`–`5×`, углы и середины сторон. Положение `CenterLower` вместе с `CenterOffsetMultiplier` задаёт смещение вниз; один шаг равен примерно 35 экранным пикселям. Настройки сохраняются рядом с исполняемым файлом.

## Автозапуск

Автозапуск выключен по умолчанию.

Чтобы включить его для текущего пользователя, нажмите `Win+R`, введите `shell:startup` и создайте ярлык на `release\win-x64\KeyboardLayoutToast.exe` (или на путь к exe, полученному собственной сборкой).

Чтобы отключить автозапуск, удалите этот ярлык из папки `shell:startup`.

## Диагностика и публикация

Ошибки записываются в `app.log` рядом с программой. Локальные настройки и журнал не включаются в GitHub-пакет. В проекте намеренно не добавлен файл лицензии: перед публикацией исходников выберите лицензию, подходящую для ваших условий.
